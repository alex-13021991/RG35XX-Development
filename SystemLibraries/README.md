# Оригинальные библиотеки

Снимок содержит отдельный архив `*-garlic.tar.gz` для каталогов `/cfw/lib` и `/cfw/usr/lib` и `*-base.tar.gz` для внешних каталогов `/lib`, `/usr/lib`, `/system/lib`, `/system/usr/lib` и `/system/usr/local/lib`. В архиве сохранены оригинальные имена и ссылки. В реестре поле `root` задаёт пространство путей. Колонка `NEEDED` содержит непосредственные зависимости динамического объекта; `SONAME` — его имя для загрузчика.

Для GarlicOS используется архив окружения `garlic`. Сведения о двух нечитаемых именах остались в манифесте. Внешний архив и архив загрузочных файлов прочитались с `TAR_RC=0`.
