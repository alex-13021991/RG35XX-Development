# Данные экземпляра

Имена каталогов содержат время начала в UTC по часам компьютера. На самом устройстве часы и часовой пояс могут отличаться. При повторном сборе создаётся новый каталог.

| Результат | Источник |
|---|---|
| Первый снимок, архивы и их SHA-256 | [Манифест](Published/20261125T155126Z/archives.json) |
| Пути, типы, цели ссылок, размеры, SHA-256, SONAME и NEEDED | [Реестр TSV](Published/20261125T155126Z/libraries.tsv) |
| Заголовки ELF, ARM attributes, импорт, экспорт и таблицы версий символов | [Текстовый реестр gzip](Published/20261125T155126Z/elf-symbols.txt.gz) |
| Уточнённые свойства Device Tree и конфигурация контроллера | [Второй снимок](Published/20261125T155454Z/) |
| Нажатия владельца, физический вывод и загрузка библиотек | [Кнопки](Published/20261125T155454Z/key-session.txt), [интерфейсы](Published/20261125T155454Z/interfaces-final.log), [проверка json-c и intl](Published/20261125T155454Z/library-check.log) |
| Производительность | [Медианы](Published/20261125T155454Z/benchmark/medians.tsv) и отдельный лог каждого запуска в том же каталоге |

В первом снимке старый BusyBox отклонил параметры `od` при чтении двоичных свойств дерева устройств. Для этих свойств используйте второй снимок, где байты прочитаны командой `hexdump`. Моментальные значения свободной памяти и частоты привязаны к конкретному файлу измерения.
