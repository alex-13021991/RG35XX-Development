# RG35XX Development — техническое исследование GarlicOS 1.4.9

**Редакция 1.0 · 26 ноября 2026 года**

Объект: оригинальная Anbernic RG35XX (2022, платформа gs705a), не RG35XX Plus, H, 2024 и не другие устройства на H700. Исследование выполнено на реальной приставке с GarlicOS 1.4.9, на Ubuntu 20.04 (e2fsprogs 1.45.5) и через ADB под Windows. Проект: https://github.com/alex-13021991/RG35XX-Development.

## Главные результаты

- Восстановлен оригинальный образ rootfs.img (200 МиБ): две повреждённые ссылки, структура ext4, служебные счётчики и overhead. Проверки e2fsck и rsync завершились с кодом 0; образ успешно загружается на реальном устройстве.
- Получен root-доступ через ADB и штатный BusyBox chroot без установки ПО на приставку.
- Физический процессор — четыре Cortex-A9, ARMv7-A, VFPv3/NEON. Ядро Linux 3.10.37 #116. Доступно 237624 КиБ RAM.
- Семь проверенных ELF штатного окружения — ELF32 ARM EABI5 soft-float, ARMv5TEJ/ARM926EJ-S. Обе SDL содержат GCC 7.3.0 (Buildroot 2018.02.9) и следы SDK `/opt/miyoo`, target `arm-miyoo-linux-uclibcgnueabi`.
- SDL 1.2.15 имеет fbcon, SDL 2.0.8 — X11 и dummy, единственный renderer программный. Для SDL2-портов требуется проверка/адаптация видеобэкенда.
- Базовый рекомендованный тулчейн — Miyoo GCC 7.3.0. Сборки для Cortex-A9 с softfp запускались на этой приставке 25 ноября. Выигрыш относительно ARM926EJ-S при одинаковой нагрузке предстоит измерить. [Бенчмарки GCC и Zig](../../../Toolchains/README.md)

## Уровни достоверности

**Измерено** — вывод команд или непосредственный анализ ELF. **Зафиксировано в ходе ремонта** — результаты, сообщённые оператором, в том числе в чате. **Вывод** — интерпретация измерений. **Гипотеза / TODO** — требует практического теста. Не считать вывод об ARMv5TEJ характеристикой всех файлов прошивки: проверено только семь образцов.
