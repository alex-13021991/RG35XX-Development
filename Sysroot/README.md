# Состав sysroot

Архив `20261125T155126Z-sysroot.tar.gz` предназначен для распаковки в файловую систему Linux. Внутри лежат `lib`, `usr/lib` и `usr/include`. Сценарии сборки умеют открыть архив сами, поэтому на разделе Windows не требуется создавать Linux-симлинки.

| Часть | Происхождение |
|---|---|
| Загрузчик, объекты .so и их рабочие ссылки | Сняты с этой приставки из корня GarlicOS |
| Заголовки C, Linux UAPI, SDL, ALSA, EGL и libstdc++ 7.3 | Локальный Miyoo SDK 7.3.0. Версии заголовков проверяются для используемого интерфейса отдельно |
| CRT, GNU ld script libc.so и архивы для линковки | Miyoo SDK с uClibc 1.0.28. crtbegin/crtend и libgcc берутся из выбранной цепочки компилятора |
| `usr/lib/libintl.so` и `usr/lib/libjson-c.so` | Ссылки для линковки добавлены только в рабочий sysroot по данным Miyoo SDK. Оба целевых файла присутствуют в оригинальном дампе. Неизменяемые архивы сбора содержат отчёт о двух EIO |
