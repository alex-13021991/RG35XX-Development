# QEMU для тестирования портов RG35XX

Подготовлена среда QEMU linux-user Cortex-A9 с библиотеками GarlicOS и программной моделью fb0/evdev/TF1/TF2/вибрации. Это среда тестирования приложений, не полная аппаратная виртуальная машина.

Инструкции: [QEMU/README.md](QEMU/README.md). Архитектура и ограничения: [QEMU/docs/ARCHITECTURE-RU.md](QEMU/docs/ARCHITECTURE-RU.md).

Игр в комплекте нет. Jazz2 проверен отдельно: [результаты](QEMU/docs/JAZZ2-TEST-RU.md).
