# Карта кнопок оригинальной RG35XX

25 ноября 2026 года владелец нажал и отпустил кнопки в указанном ниже порядке. Тест открыл `/dev/input/event1` (`RG35XX Gamepad`) и временно получил эксклюзивный ввод через `EVIOCGRAB`. Для каждой из 17 кнопок записана пара событий. После теста дескриптор закрыт. [Запись с метками времени](../HardwareDump/Published/20261125T155454Z/key-session.txt)

| Надпись | Тип evdev | Код hex | Нажато → отпущено |
|---|---|---|---|
| ↑ | EV_ABS | 0x0011 | −1 → 0 |
| ↓ | EV_ABS | 0x0011 | +1 → 0 |
| ← | EV_ABS | 0x0010 | −1 → 0 |
| → | EV_ABS | 0x0010 | +1 → 0 |
| A | EV_KEY | 0x0130 | 1 → 0 |
| B | EV_KEY | 0x0131 | 1 → 0 |
| X | EV_KEY | 0x0133 | 1 → 0 |
| Y | EV_KEY | 0x0134 | 1 → 0 |
| L1 | EV_KEY | 0x0136 | 1 → 0 |
| R1 | EV_KEY | 0x0137 | 1 → 0 |
| L2 | EV_ABS | 0x0002 | 255 → 0 |
| R2 | EV_ABS | 0x0005 | 255 → 0 |
| Select | EV_KEY | 0x013a | 1 → 0 |
| Start | EV_KEY | 0x013b | 1 → 0 |
| Menu | EV_KEY | 0x013c | 1 → 0 |
| Vol+ | EV_KEY | 0x013d | 1 → 0 |
| Vol− | EV_KEY | 0x013e | 1 → 0 |

**Power.** Отдельный драйвер `atc260x_onoff` зарегистрировал единственную клавишу `EV_KEY 0x0074` (KEY_POWER) на `event0`. Основание — возможности драйвера. Физическое нажатие Power и аппаратный Reset в эту сессию не входили. Остались также объявленные возможности геймпада, например `0x0135`, которые не появились в записанной последовательности. [Возможности устройств и настройки RetroArch](../HardwareDump/Published/20261125T155454Z/input.txt)

В приложении при перечислении устройств стоит проверять имя через `EVIOCGNAME`. Направления и триггеры надо читать как абсолютные оси. В конфигурации RetroArch встречаются собственные индексы вроде `h0up` и `+2`. Таблица выше содержит исходные Linux-события до преобразования в SDL или RetroArch. [Программа записи](../TestPrograms/keys.c)
