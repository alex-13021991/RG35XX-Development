# Восстановленный rootfs.img · GarlicOS 1.4.9 для оригинальной RG35XX

Владелец передал этот образ отдельным файлом 26 ноября 2026 года после ремонта и проверки загрузки на приставке. ZIP содержит один файл `rootfs.img` размером 209715200 байт (200 МиБ). Его SHA-256 — `23ef20aa8c43f66436b5210171982b7e3563741d6258f014f020933ff70f7635`. [Скачать ZIP](rootfs.img.zip) · [SHA-256 распакованного файла](SHA256SUMS)

## Извлечение после клонирования

В Linux или WSL из этого каталога выполните

```sh
unzip rootfs.img.zip
sha256sum -c SHA256SUMS
```

В PowerShell из этого каталога выполните

```powershell
Expand-Archive -LiteralPath .\rootfs.img.zip -DestinationPath .\extracted
Get-FileHash -Algorithm SHA256 -LiteralPath .\extracted\rootfs.img
```

## Проверка перед публикацией

На переданном файле `e2fsck -fvn` 1.47.0 прошёл все пять этапов и вернул 0. Обе ссылки в `/usr/lib` ведут к нужным версиям. SHA-256 содержимого `libintl.so.8.1.5`, `libjson-c.so.3.0.1` и `libao.so.4.1.0` совпали с протоколом ремонта. Состояние суперблока переданной копии — `not clean`, checksum — `0x084e138f`. Во время проверки WSL также сообщил, что метки последнего монтирования и записи опережают его часы менее чем на сутки. В выписке оператора для более ранней офлайн-проверки указаны `clean` и `0x96448b19`. У переданного файла те же счётчики свободных блоков (69990), свободных inode (48485) и overhead (14399).
