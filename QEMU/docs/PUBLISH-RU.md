# Подготовка к GitHub и повторное создание

На этапе подготовки исходные скачанные репозитории не редактировались; публикация выполняется из отдельной рабочей копии. Подготовлен отдельный архив `RG35XX-QEMU-v0.1.0-github.tar.gz`: внутри QEMU/ и README-QEMU.md для корня технического репозитория. Также лежит необязательный QEMU-README.patch с добавлением ссылки в существующий README.md.

При использовании уже опубликованного каталога QEMU повторная распаковка не нужна. Следующие команды предназначены для переноса исходного архива в другую рабочую копию; README-патч применяют только если ссылка ещё отсутствует.

```bash
tar -tzf RG35XX-QEMU-v0.1.0-github.tar.gz
cd /path/to/working-copy/RG35XX-Development
tar -xzf /path/to/RG35XX-QEMU-v0.1.0-github.tar.gz
# Необязательно, после просмотра:
git apply --check QEMU-README.patch
git apply QEMU-README.patch
```

Просмотрите diff и добавьте только нужные файлы своим обычным способом. Скриптов автоматического commit/push здесь нет.

## Состав архивов

| Архив | Содержание |
|---|---|
| github | Скрипты, модель устройств на C, исходник demo, тесты, русская документация, лицензия. Нет build, runtime, state, отчётов с кадрами или какой-либо игры |
| ready-local | То же плюс собранные ARM-компоненты и проверенный sysroot из технического профиля. Нет игр, игровых библиотек, пользовательских сохранений и журналов |

GitHub-архив восстанавливает runtime из существующего `Sysroot/20261125T155126Z-sysroot.tar.gz`, сверяя SHA-256. SDK и host qemu-user/proot устанавливаются отдельно. Набор не скачивает исполняемые файлы из случайных сторонних источников и не содержит абсолютных путей сборки в launcher.

**ready-local предназначен для локального использования.** У runtime множество upstream-компонентов с собственными лицензиями. Этот архив не является подготовленным лицензионным source-offer для их бинарного распространения. Для публичной выкладки среды используйте github-архив и существующий sysroot технического репозитория. Если будете публиковать готовый runtime Release, отдельно сопоставьте лицензии всех компонентов и разместите требуемые соответствующие исходники/уведомления. GPL файла LICENSE относится к новым исходникам набора, а не перелицензирует библиотеки GarlicOS.

## Повторное создание

После размещения QEMU/ в техническом репозитории:

```bash
cd QEMU
./scripts/setup.sh
python3 tests/selftest.py
./rg35xx run
```

При нестандартной раскладке:

```bash
RG_TOOLCHAIN=/path/to/miyoo-gcc-7.3.0 \
  ./scripts/setup.sh /path/to/20261125T155126Z-sysroot.tar.gz
```

Нужен Linux/WSL с рабочими Linux-ссылками. Распаковывайте ready-local в домашний каталог WSL, а не средствами Windows на NTFS. Host-пакеты проверены на Ubuntu 24.04 x86_64. Ubuntu 20.04 не проверялась. Кросс-компилятор Miyoo GCC 7.3.0 x86_64 может потребовать его собственные host-библиотеки; build.sh добавляет toolchain/lib только на время сборки.

## Пересборка архивов

```bash
python3 scripts/package.py /mnt/d/Temp/RG35XX/Out
```

Создаётся проверенный набор с SHA256SUMS. Упаковка выбирает файлы по списку разрешённых каталогов, исключает игру, state/, reports/, __pycache__ и .git. После создания архивы ещё раз проверяются на отсутствие игровых payload. Время gzip нормализовано; содержимое зависимостей/версии компилятора всё равно должно совпадать для воспроизведения бинарных хешей.
