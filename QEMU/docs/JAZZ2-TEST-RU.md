# Отдельная проверка Jazz² Resurrection / Jazz2 RG35XX 1.1.0

Игра целиком находится отдельно от среды и пакета для GitHub. В наборе нет её ELF, ресурсов Content, частных библиотек, картинок, сохранений и исходников движка. Скрипты в tests лишь принимают внешний каталог игры.

Проверялся предоставленный `Jazz2_RG35XX_v1.1.0_ready-to-play.zip`. SHA-256 входного архива указан в provenance.json. Его копия распакована в `~/RG35XX/Work/qemu-audit/jazz2-package`, оригинальный ZIP не изменялся. Игровой ELF и частные библиотеки в этой работе не пересобирались и не патчились; к ним применялся только внешний preload модели устройств.

## Результат

- Оригинальный пакет загрузил `prince/01_castle1` (Dungeon Dilemma).
- В первом интервале обнаружено 139 разных ненулевых снимков framebuffer; это число выборок, не FPS.
- Стрельба дала 61 различный снимок за следующий интервал и значения moto 0 и 20. Физический мотор отсутствует: проверялись запросы игры.
- Работают движения, действие A, пауза Start и Menu. Проверка не охватывает все уровни и все варианты настроек.
- MENU записал нативное состояние (1354 байта) и config (364 байта), игра завершилась с кодом 0.
- После повторного запуска Continue загрузил сохранение; в журнале есть `Resuming saved state` и повторная загрузка уровня. Следующий MENU снова завершил игру с кодом 0.
- Чистый запуск без config/RG35XX.options выбрал внутренние 320×240, вывод 640×480 RGB565 и лимит игрового FPS 45. MENU сохранил состояние и завершил процесс.
- Кадр уровня и экран паузы просмотрены визуально. Звук был отключён через OpenAL null; его звучание не проверялось.

**Фактическое быстродействие реальной приставки по сообщению владельца: 40–45 FPS с настройками по умолчанию.** Это наблюдение владельца, а не измерение в текущем прогоне. Скорость QEMU/PRoot/просмотрщика не используется для оценки производительности RG35XX.

## Ручной запуск в подготовленной WSL

```bash
cd ~/RG35XX/QEMU
./rg35xx run --session jazz2-play \
  --app "$HOME/RG35XX/Work/qemu-audit/jazz2-package/Roms/PORTS/Jazz Jackrabbit 2" \
  --exec jazz2 -- /config /mnt/mmc/CFW/Jazz2.config
```

Сразу на уровне:

```bash
./rg35xx run --session jazz2-level \
  --app "$HOME/RG35XX/Work/qemu-audit/jazz2-package/Roms/PORTS/Jazz Jackrabbit 2" \
  --exec jazz2 -- /config /mnt/mmc/CFW/Jazz2.config /level prince/01_castle1
```

Повторение автоматических проверок:

```bash
python3 tests/jazz2.py "/path/to/Jazz Jackrabbit 2"
python3 tests/default-jazz2.py "/path/to/Jazz Jackrabbit 2"
```

Тесты используют отдельные сеансы jazz2-test и jazz2-default; второй очищает только три файла настроек своего тестового сеанса. Для собственной игры используйте другое имя, например jazz2-play.

Рабочие журналы и кадры находятся в state/ и reports/ локальной среды. Они не входят в архив для GitHub или готовый runtime-архив. Путь сохранения при нашем прямом запуске отличается от штатного launch.sh: мы явно используем TF1 CFW. Для реального launch.sh остаётся проверка на устройстве.
