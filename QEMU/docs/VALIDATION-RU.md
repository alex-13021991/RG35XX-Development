# Проверки 27 ноября 2026 года

Платформа: Ubuntu 24.04 x86_64, WSL2, qemu-arm 8.2.2, PRoot 5.1.0, Miyoo GCC 7.3.0. Sysroot, коммиты исходных репозиториев и хеш входного игрового архива записаны в provenance.json.

| Проверка | Результат |
|---|---|
| Сборка shared preload, demo и probe основным тулчейном | PASS, Cortex-A9/NEON softfp/uClibc |
| fb0 и fb1: размеры, stride, bpp, mmap | PASS |
| fb0: допустимый page pan и отказ для выхода за буфер | PASS |
| evdev: имя RG35XX Gamepad, диапазоны D-pad/триггера | PASS |
| Оригинальные SDL1 и SDL2: загрузка и VideoInit dummy | PASS |
| TF1 и TF2: отдельные файлы в отдельных каталогах | PASS |
| Динамические RGB565-кадры demo | PASS |
| Нажатие/отпускание A -> moto 255/0 | PASS |
| MENU -> нормальный выход demo | PASS |
| Реальное окно Tk/WSLg и преобразование RGB565 в изображение | PASS, окно открывалось и автоматически закрывалось тестом |
| Присланный Jazz2: уровень, кнопки, эффекты, сохранение, Continue | PASS, подробнее JAZZ2-TEST-RU.md |
| Jazz2 с чистыми настройками | PASS: 320×240 -> 640×480, limit 45 |

Проверка изображения: RGB565 demo и кадр уровня Jazz2 просмотрены визуально; цвета/ориентация согласуются с ожидаемыми. Это не сравнение побайтно с HDMI/экраном реальной приставки.

Для повторения общих тестов: `python3 tests/selftest.py`. Тест с WSLg открывает окно примерно на секунду; без DISPLAY графический этап пропускается. Без игры общие проверки полностью автономны после setup.

Непроверенное: физическое устройство в этой сессии, аудиовывод, полная плата/прошивка, точные затраты RAM и скорость CPU, SD/FAT-контроллеры, все приложения и все уровни игры. Нет утверждения о полноценной аппаратной VM RG35XX.

Проверки чистого восстановления из github-архива, содержимого архивов и неизменности Git-репозиториев зафиксированы на этапе подготовки до публикации в packaging-validation.json рядом с документацией.
